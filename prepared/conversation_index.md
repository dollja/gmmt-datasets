## Werewolf

Full per-game inventory blocked until Hugging Face transcript and split files are acquired. Do not treat the repository code as a transcript. Official dataset card describes 151 YouTube games and 48 Ego4D games. Game parts in Ego4D must be grouped before counting independent conversations.

Browse source inventories: [YouTube transcripts](https://huggingface.co/datasets/bolinlai/Werewolf-Among-Us/tree/main/Youtube/transcripts), [Ego4D files](https://huggingface.co/datasets/bolinlai/Werewolf-Among-Us/tree/main/Ego4D). No listed game has been selected for the initial 20.

## Transcript preparation contract

For every acquired conversation produce a curator-only complete readable transcript and structured JSON with speaker, utterance ID, verbatim text, source file, source element/line and timestamp where available. Preserve original IDs. Document generated stable IDs separately when originals are absent. Preserve the raw source bytes. Keep existing annotation fields out of the derived dialogue text. Do not use GMMT RE-marked output as observer text. Verify one-to-one source coverage and ordering; handle missing MapTask utterance IDs explicitly rather than silently adopting imputed IDs as original.

Only after you select an episode and first-response cutoff may its complete prefix be exported to an initial annotation view. Full transcripts are never that initial view by default.
